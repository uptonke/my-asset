# Optimizer Phase 3: conditional BL scenarios and cost-aware optimization

Run Optimizer Lab / all_optimizer_outputs. Phase 3 uses the exact in-memory common snapshot saved only in RUNNER_TEMP as a non-pickle NPZ; it verifies its fingerprint and matches both the expected-return and BL reports' snapshot IDs. It runs after the existing v3.1/v3.2 builders. Results are stored only in the separate phase3 object of skfolio_sandbox_latest.json. Standalone solver runs remove old phase3 output until a new shared run; formal decision and trade generation still use the legacy portfolios object.

Existing v3.2 policy disables absolute forecasts and maximum Sharpe. This change does not alter it. The new BL return vector is a hypothetical annual TWD excess-return scenario, with reference-implied prior pi = risk_aversion * covariance * current weights (not a market equilibrium portfolio), 20% diagonal covariance shrinkage, tau .05 and bucket-relative views. Scores already include v3.1 rule adjustments, not added twice. Each score unit implies a configurable 1 percentage point relative annual shift from the prior, uncertainty from view variance and confidence capped at .75. No statistical calibration of those shifts or costs has been established.

Hard Phase 2 allocation constraints and 15% one-way turnover cap apply in each solver. Base net modeled annual excess return floor equals the current portfolio's modeled excess return. Cost assumptions per side: cash 5bp, gold/global equity 15bp, Taiwan equity 35bp, crypto 50bp. Cost = sum(rate * absolute weight changes), not half turnover. Target-return CVaR minimizes daily historical tail loss subject to the net floor; cost-aware CVaR adds cost divided by 252 sessions; annual mean-variance minimizes risk-aversion/2 times annual variance minus scenario excess return plus one-off cost. Costs are estimates, not broker quotes, and do not account for lots or taxes separately. Annual floor assumes one reallocation and one year holding. Daily penalty sensitivity varies amortization, not the annual return floor.

Sensitivity: 0.5x/2x costs, zero/2pp score scale, -2pp annual floor, 21/63-day cost amortization. No automatic constraint relaxation. Infeasible candidates are reported without weights; no ranking or trade promotion. Historical risk statistics are in-sample, not realized forward performance. Future work: walk-forward evaluation with historical point-in-time priors and actual per-asset transaction costs, and policy approval before formal integration.
